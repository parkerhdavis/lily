# Archive

Retired tooling kept for reference.

`SDT Tooling/` holds the old SDT authoring, validation, migration, and corpus tools, retired when the plan engine and the holotype templates replaced the SDT fill path. The live path is the plan renderer in `apps/desktop/backend/src/plan.rs`, the compiler in `scripts/lily_compile.py`, and `scripts/lily plan render/audit`. The old golden corpus moved to the Carelaw repository's `Archive/SDT Golden Corpus/`.
